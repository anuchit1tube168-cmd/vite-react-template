# ASTRA Read brand

ASTRA Read is the shipping identity for this clean-room build. It intentionally does not reuse the reference product name, logo, cover artwork, signature copy, or visual identity.

## Positioning
A focused, modern Thai/English serialized-fiction reader that feels calm, fast and personal.

## Visual family
Indigo `#5B5BD6` is the primary action color, teal `#14B8A6` is secondary, with soft neutral surfaces and generated geometric covers. This differs from the reference product's identity while keeping familiar reader UX patterns.

## Voice
Clear, warm, concise, product-first. Thai UI labels are natural rather than copied phrases.

## Logo brief
Wordmark: `ASTRA Read`; optional abstract star/page glyph. Do not use the target mark, target letterform, target cover art, or confusingly similar iconography.

## Release sweep
Before launch, search code/assets/metadata for `aNovel`, target domains, target cover filenames, target story titles and target copy. Planning evidence may remain only under `replica/`; none of it ships.
